This module is holds an [Obsidian](https://obsidian.md/) vault that describes a simple process followed for creating this PubMed MCP Server in Rust. 

While I'm familiar with Jira, Linear, and other ticketing software and practices such as Agile, Scrum, Kanban, and Agent workflows - I threw this together as a simple example of a way that I can work: Planning out a project, creating tickets for it, and tracking their progress while I work.
